# Runner 架构与恢复导航

正常路径采用 GARM v0.2.1 与上游 LXD provider v0.1.5，由 GitHub 原生 job container 消费固定 Kiln。GARM、provider 和 LXD 拥有正常生命周期。目标架构已采用，标准路径的真实 VM、私有拉取和故障验收尚未完成；文档与源码交付不表示部署切换完成。

- [目标架构与迁移边界](architecture.md)：组件职责、最小定制、安全边界、正常删除和异常停接，以及待选的标准路径验证。
- [跨仓库 CI 与 Kiln](../ci-architecture.md#runner-与-kiln)：不可信池、私有镜像消费、业务检查、缓存和启用验收。
- [历史恢复责任](records-recovery.md)：原身份、unknown、不重发、现场原件，以及准确历史源码与恢复版本的追溯。

自研 guard、watchdog、admin、bootstrap 和 firewall 程序、模板及专用构建检查已退出主线。它们的源码与实施说明通过 Git 历史追溯，不再提供当前安装或构建入口。运行现场继续由原恢复 owner 按实际安装版本和原记录处理；源码退役不停止服务、不改变凭据，也不结束旧操作。

本目录仅保留架构与恢复文档。文档和通用工具检查使用[根目录入口](../README.md#格式与工具检查)。后续配置、镜像或消费适配随首个实际消费者交付，不预建通用管理程序。实际部署、启用及历史恢复分别绑定目标、前态、授权和验收。
